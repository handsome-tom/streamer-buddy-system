Notification gallery

Every notification, taken from the demo and drawn with the real stylesheet: the streamer's OBS chat dock first, then the mod's Chrome side panel. They're collected once and kept in this browser, so the page opens at once; the styles are fresh on every reload, so design changes show straight away. Press Collect again only when a notification itself changes (new parts or words). Animations play once as a frame loads; right-click a frame → Reload frame to see one again.
